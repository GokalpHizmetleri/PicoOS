Explore GitHub runs entirely in your browser: it searches GitHub, checks every repository for a web app that runs on the Pico (index.html, no build step, small enough) and downloads the files straight from GitHub.

Without a token GitHub allows about 10 searches per minute. A token without any scopes (fine-grained, public repositories read-only) raises that to 30 per minute. It is only sent to api.github.com, never to the Pico.
